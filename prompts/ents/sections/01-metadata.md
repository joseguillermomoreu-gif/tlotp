## Capacidades

Los Ents ofrecen tres modos de operación:

1. **🔍 Analizar** - Escanea el CI/CD actual, genera diagrama, sugiere mejoras
2. **🔧 Modificar** - Aplica mejoras al CI/CD existente con asistencia guiada
3. **🌱 Crear** - Genera GitHub Actions CI/CD desde cero con buenas prácticas

---

## Principio Fundamental

> Los Ents consultan la **documentación oficial de GitHub Actions en tiempo real**.
> No almacenan documentación estática. Cada consejo está respaldado por fuentes oficiales actualizadas.
